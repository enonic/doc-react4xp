= React4XP reference documentation
:toc: right

React4XP lets front-end developers build *Enonic XP applications with React*. React components are rendered <<ssr#, server-side>> and then <<hydration#, hydrated>> in the browser by default, so the same React code runs on both the server and the client (isomorphic rendering).

NOTE: This documentation covers *React4XP 7.x*, which builds on *React 19* and requires *Enonic XP 8*.

TIP: New to React4XP? Start with the https://developer.enonic.com/learn/react4xp-tutorial[React4XP tutorial] for a hands-on, guided introduction - this reference documents the library and framework in depth.

== How React4XP is distributed

React4XP comes in two parts:

*Library* (`lib-react4xp`)::
The Enonic XP library that does the rendering. It exposes the `render` and `processHtml` functions, the `DataFetcher` class and the `React4xp` object - all documented in the <<library#, Library reference>>. Available on https://market.enonic.com/vendors/enonic/react4xp-lib[Enonic Market] and https://github.com/enonic/lib-react4xp[GitHub]. Your React sources are compiled by the companion npm build tool `@enonic/react4xp` (https://www.npmjs.com/package/@enonic/react4xp[npm]).

*Starter* (`starter-react4xp`)::
A ready-to-run project that bundles the library, the `@enonic/react4xp` build integration, and a Hello world setup - so `enonic project create` gives you a working React4XP setup in one step. Documented in the <<starter#, Starter reference>>; available on https://market.enonic.com/starters/react4xp-starter[Enonic Market^] and https://github.com/enonic/starter-react4xp[GitHub^].

A fully working demo application is available on https://market.enonic.com/vendors/enonic/react4xp-demo[Enonic Market^].
